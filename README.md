# 🎮 Tic-Tac-Toe Game

A fully functional **Tic Tac Toe game** built with **HTML, CSS, and JavaScript**.  
Play the classic 3x3 grid game with real-time turn updates, interactive animations, and a responsive design.  
Take turns as **X** or **O**, and try to get three in a row before your opponent!  

---

## 🎯 Controls

- Click on an empty cell to place your **X** or **O**.  
- The game automatically switches turns between players.  
- Press the **Restart Game** button to start a new match.  

---

## ✨ Features

- Clean and responsive UI with **modern styling** and smooth hover effects  
- Highlights winning combination dynamically  
- Real-time **game status updates** (who’s turn, winner, or draw)  
- Supports restarting the current game at any time  
- Lightweight and fast, works in any modern web browser  
- Beginner-friendly and easily modifiable code  

---

## 🛠 Requirements

- Modern web browser (Chrome, Firefox, Edge, Safari)  
- No external dependencies required
